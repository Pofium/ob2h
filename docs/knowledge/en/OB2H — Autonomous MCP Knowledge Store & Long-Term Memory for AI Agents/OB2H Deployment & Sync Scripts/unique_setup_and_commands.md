PC-side install/uninstall via `install.bat` / `uninstall.bat` (wraps `powershell -ExecutionPolicy Bypass`). Register the sync task manually with `powershell -File scripts\pc\sync-task.ps1 -Register`. VPS deployment requires copying `ob2h-sync.service` and `ob2h-sync.timer` into `/etc/systemd/system/`, then `systemctl daemon-reload && systemctl enable --now ob2h-sync.timer`. The VPS update script must be run from MSYS Git Bash with `MSYS_NO_PATHCONV=1` set so Windows paths are not converted.
