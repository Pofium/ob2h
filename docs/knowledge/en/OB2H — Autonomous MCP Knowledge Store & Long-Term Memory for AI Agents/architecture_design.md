The root is a Cargo workspace centered on one crate (`ob2h`, v1.9.9) whose CLI entry point (core_engine) wires configuration, background workers, and all subcommands; the same binary is re-exported as a library consumed by two language-specific plugin crates (plugins/) so both Hermes (Python) and DeepSeek Harness (cordis) call into identical Rust logic. Cross-cutting concerns are shared at this level: SQLite + sqlite-vec for persistence, Candle (Qwen3-0.6B) for local embeddings, XChaCha20-Poly1305 secrets vault isolated from memory/graph/sync bundles, SSH delta-bundle sync with optional AES-GCM E2EE, and a self-update loop over GitHub Releases. The integration_tests crate exercises the core against real SQLite/temp dirs, while scripts_deploy/ and skills_catalog/ provide platform installers, systemd timers, and per-agent SKILL.md docs that reference the same CLI surface documented in README.md. Versioning and roadmap are tracked through PLAN_v*.md files plus CHANGELOG.md.
