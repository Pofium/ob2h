Flat collection of `test_*.rs` files under `tests/`, each a Cargo test binary that imports the library via `ob2h::...` (no shared test harness). Tests are grouped by feature area: DB/schema (`test_db.rs`, `test_migration_m3.rs`), memory/vector search (`test_memory.rs`, `test_vector.rs`, `test_bench.rs`, `test_embedding_local.rs`), project graph/AST (`test_graph.rs`, `test_ast_extractor.rs`, `test_repomap.rs`, `test_callpath.rs`, `test_typepass.rs`), sync across peers (`test_sync.rs`, `test_sync_v2.rs`, `test_sync_e2ee.rs`), MCP server contract (`test_mcp.rs`, `test_mcp_resources_prompts.rs`), secrets vault (`test_secrets_*.rs`), lifecycle phases (`test_lifecycle_*.rs`), and CLI/observer features (`test_viewer.rs`, `test_watcher.rs`, `test_git_hooks.rs`). Each file is self-contained: it constructs an `AppContext` via `init_app(Settings { data_dir, embed_provider: "fake" })` backed by `tempfile::tempdir()`, runs async operations with `#[tokio::test]`, and asserts on returned strings or direct DB queries through `db.with_conn`. There is no cross-file test fixture module — helpers live inline per file.
