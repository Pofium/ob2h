The `ob2h install` / `uninstall` commands rewrite `$LOCALAPPDATA\hermes\config.yaml` (Windows) or `~/.hermes/config.yaml` (Linux) by injecting/removing an `ob2h:` MCP server block with `command: serve` and default env vars pointing to DeepSeek. The `plugin install/uninstall/status` and `skill install` commands deploy assets under `$HERMES_HOME/plugins/ob2h` and `$HERMES_HOME/skills/devops/ob2h/SKILL.md`, resolving `HERMES_HOME` first, then `%LOCALAPPDATA%\hermes`, then `~/.hermes`.
