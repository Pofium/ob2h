Three-file leaf module forming the process boundary of the `ob2h` crate:
- `src/config.rs` defines the central `Settings` struct and `Settings::from_env()`, loading every runtime knob from `OB2H_*` environment variables with defaults, plus `.env` fallback for `OB2H_LLM_API_KEY` and path helpers (`db_path`, `workspace_dir`, `logs_dir`, `ensure_dirs`).
- `src/lib.rs` is the library root: re-exports all feature modules (`backup`, `cli`, `config`, `consolidator`, `db`, `dream`, `embedding`, `extractor`, `graph`, `ingest`, `lifecycle`, `llm`, `mcp`, `memory`, `project`, `ralph`, `secrets`, `sync`, `update`, `vector`, `viewer`, `workspace`) and exposes two public constructors: `init_app(settings)` which builds the shared `Arc<AppContext>` (DB, embedder, memory, workspace, graph, project, ralph, secrets, dream, backup, sync, lessons, slots, watcher, scan_jobs) and `start_background_workers(ctx)` which spawns AutoDream/AutoSync workers.
- `src/main.rs` is the `#[tokio::main]` entry: parses `clap::Parser` CLI, handles the special read-only `Viewer` subprocess before `init_app`, sets up `tracing_subscriber` (file + stderr), dispatches every `Commands::*` variant to its handler (most of which call into `ob2h::cli::*` or invoke `McpServer::call_tool`), and additionally implements Hermes integration helpers (`plugin_install/uninstall/status`, `skill_install`, `install_to_hermes/uninstall_from_hermes`) that write Python plugin files and YAML blocks into `$HERMES_HOME`.
Dependency direction is one-way: `main` → `lib` (via `ob2h::` prefix) → feature modules; no cross-imports between sibling feature modules at this level.
