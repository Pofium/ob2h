Flat collection of one subdirectory per supported agent (claude-code, codegraph, codex, cursor, deepx, dsh, gemini-cli, hermes-agent, kilo-code, kimi-code, mimo-code, ob2h, ob2h-zcode, opencode, qoder, qwen-code, ralph-loop, trae, windsurf, zcode), each containing a single `SKILL.md` file. Every file follows the same frontmatter schema (`name`, `description`) followed by sections: Installation/Environment, OB2H Integration (MCP config path, install/status via `ob2h agent install --agent <name>` and `ob2h agent status`), Key skill commands, and Pitfalls. The module is purely declarative documentation consumed by agents to discover how OB2H is wired on this machine; there is no executable code inside the scope.
