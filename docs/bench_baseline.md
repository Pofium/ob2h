## Чтение результатов

- **search recall@5 = 0.222** — главная находка baseline: гибридный поиск плохо ранжирует
  перефразированные запросы в топ-5 (FTS-trigram не матчит синонимы, семантика MiniLM
  недостаточна или теряется в RRF). Цель Фаз 22/25 — поднять recall@5 search-режима.
- **context recall = 0.833** — смещено вверх устройством golden set (записи набраны из
  high-importance пула, а build_context берёт топ-100 по importance). После Фазы 22
  (гибрид в build_context) сравнивать с этим числом корректно только с оговоркой;
  честная метрика context-режима — recall на записях вне топа важности.
- Латентность search p50 70 мс определяется инференсом Candle MiniLM на CPU
  (брутфорс по 278 векторам памяти пренебрежим); критерий sqlite-vec из §8
  (p95 > 80–100 мс) оценивать на графе (~600K векторов), не на памяти.

> Гейт (ADR-13): изменения формул релевантности/квантования принимаются,
> пока recall@k не ниже baseline − 2 п.п.

## Пост-Фаза 22 (2026-09-13): честный prefetch в живом коде

| Режим | recall@5 | recall@10 | MRR | пусто | p50, мс | p95, мс |
|---|---|---|---|---|---|---|
| search (после Ф22) | 0.222 | 0.306 | 0.198 | 0/36 | 87.8 | 165.9 |
| context (после Ф22) | 0.542 | 0.542 | 0.583 | 15/36 | 82.2 | 109.7 |

Интерпретация:
- **search без изменений** — пайплайн `memory_search` Фазой 22 не трогался (регрессии нет;
  рост p50/p95 — шум живой системы).
- **context 0.833 → 0.542** — ожидаемое падение против смещённого baseline (см. выше):
  блок теперь собирается реальным гибридным поиском по запросу, а не «топом важности
  независимо от запроса». 15/36 коротких запросов дали пустой гибрид-пул и безопасно
  ушли в importance-fallback (их вклад ≈ старые 0.83). Производственный prefetch ходит
  с полным текстом хода (не коротким запросом) — для него гибрид-пул пустым практически
  не бывает, а FTS-trigram на длинном тексте матчит шире.
- Бюджет 8000 символов и touch только вошедших записей проверены юнит-тестами
  (`tests/test_context_v2.rs`); в bench эти эффекты не видны напрямую.
- Новый целевой ориентир для Фаз 25/29: поднять recall@10 search-режима ≥ 0.5.
